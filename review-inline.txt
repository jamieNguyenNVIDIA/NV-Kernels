Top commit deep-dive
====================

REACHABILITY: confirmed. arm_smmu_def_domain_type is wired into
arm_smmu_ops.def_domain_type, called by the IOMMU core for every
PCI device on an ARM SMMUv3 system at probe.

The new check inside the existing dev_is_pci(dev) branch:

    if (pdev->bus->self &&
        (pdev->bus->self->dev_flags &
         PCI_DEV_FLAGS_PCI_BRIDGE_NO_ALIAS) &&
        pdev->bus->self->vendor == PCI_VENDOR_ID_ASPEED &&
        pdev->bus->self->device == 0x1150)
            return IOMMU_DOMAIN_IDENTITY;

  - pdev->bus is guaranteed non-NULL for any probed PCI device.
  - pdev->bus->self is explicitly NULL-checked (NULL only on root bus).
  - The vendor+device check is technically redundant given the AST1150
    quirk is the only setter of PCI_BRIDGE_NO_ALIAS today, but
    defensive in case another driver ever sets the same flag.
  - Pattern is consistent with the existing HISI PTT and NVIDIA quirks
    in the same function.

No race, no leak, no UAF surface — purely a domain-type policy
decision at probe time.

No regressions.
